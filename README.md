# 科研绘图PPT

从草图到成品的科研绘图资料仓，集中收录多个项目的绘图源文件、海报、报告幻灯片与其他可编辑展示资产。
论文项目中的画图 PPT 会尽量保留从草稿到成品的逐步修改过程，方便查看结构组织、视觉层级、配色和排版如何一步一步完善。
